# Wall-in

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

User-specified Vite, React, TypeScript. Rust serves the production static build and JSON API on 127.0.0.1:3977.

## Users and purpose

Linux desktop users managing local wallpapers and imported Steam Wallpaper Engine projects across desktop environments.

## Capabilities and constraints

The library uses actual backend state only. Import takes an absolute local path; browsers cannot resolve a file picker's absolute path. Image/video playback depends on installed desktop integration. Web, scene, and application renderers are not implemented. Playlist and automation preferences may persist but must not imply functioning scheduling or policies. No generated or fabricated wallpaper imagery, counts, or support claims.

## Brand commitments

User-approved Operate direction: dark graphite desktop tool, warm off-white type, restrained lime accent, library gallery centerpiece, sidebar navigation, responsive mobile layout. Build directly in code without image generation or further creative confirmation gates.
