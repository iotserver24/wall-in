# Rainmeter limited skin compatibility

`crates/rainmeter` is an independent, non-executing Rust reader. Its MIT-licensed implementation and original test fixtures contain no copied Rainmeter source, skins, artwork, or documentation text. Official [Rainmeter source](https://github.com/rainmeter/rainmeter) is GPL-2.0 (see its [LICENSE](https://github.com/rainmeter/rainmeter/blob/master/LICENSE)); its license does not become the license of this independent implementation. No upstream checkout is included in the deliverable or required to build it. Do not copy upstream code or bundled assets into this crate without a separate license review.

References: official [skin structure](https://docs.rainmeter.net/manual/skins/), [variables](https://docs.rainmeter.net/manual/variables/), [String](https://docs.rainmeter.net/manual/meters/string/), [Image](https://docs.rainmeter.net/manual/meters/image/), [Shape](https://docs.rainmeter.net/manual/meters/shape/), [includes](https://docs.rainmeter.net/manual/skins/include-option/) and [plugins](https://docs.rainmeter.net/manual/plugins/) documentation. The implementation is intentionally not a full Rainmeter interpreter.

## Supported subset

Call `wall_in_rainmeter::inspect_skin(root, "Skin.ini") -> Result<Report, Error>`. `root` is the extracted, trusted skin directory, not a Rainmeter package; the `.ini` argument is a relative path inside it. `Report.meters` is an ordered, declarative list for a parent renderer; `Report.diagnostics` explains omitted sections/options. `Error` denotes a rejected entry INI or malformed input. The crate is part of the root workspace and powers the service's widget import API. To test: `cargo test --workspace --jobs 2`.

* UTF-8 (including BOM) and UTF-16 LE BOM INI, case-insensitive section/option names, `;` line comments, and `[Variables]` with bounded, recursive `#Name#` expansion. `#@#` resolves to the `@Resources/` directory under `root`.
* Static `Meter=String` (also accepts `Meter=Text` as a convenience alias): `Text`, `FontFace`, `FontSize`, `FontColor`. A String meter may bind one local `Measure=Time` section using `MeasureName`, `Text` containing exactly one `%1`, and a bounded `Format` using only `%H`, `%M`, `%S`, `%I`, `%p`, `%d`, `%m`, `%Y`, `%A`, `%a`, `%B`, `%b`, or `%%`. The GNOME bridge updates it once per second with a short text fade. Static `Meter=Image`: `ImageName` pointing to an existing local PNG/JPEG/BMP file. Static `Meter=Shape`: four-argument `Rectangle` and `Ellipse`, optionally `| Fill Color R,G,B[,A]`. All three support finite, bounded numeric `X`, `Y`, `W`, `H` (defaults: origin 0, sizes unspecified); RGB/RGBA colors use decimal bytes.
* Images are returned as local paths, not decoded or opened by this crate. No pixel/font layout or painting occurs here. The parent renderer is responsible for decoding and for enforcing image bounds and format validation at display time. The crate checks image extension, file size, existence and path safety, **not image contents**.

## Security and deliberate exclusions

No code execution, measures other than the restricted local Time format, plugin/DLL loading, Lua, bangs, external commands, network fetching, `@Include`, action options, dynamic variables, other measure bindings, unknown meter options, or unsupported shape operations. Unsupported sections are omitted with diagnostics. A suspicious value in a supported meter rejects that meter rather than executing or interpreting it. Rainmeter-specific relative coordinates, conditional logic, arbitrary section-variable expressions, custom font loading, other animations and arbitrary runtime updates are not implemented. Options under `[Rainmeter]` are not applied; dangerous ones are flagged. This is a limited import subset, not behavioral equivalence. Wall-in renders static Text and bound Time meters as noninteractive GNOME background widgets. Image and Shape meters are parsed but omitted from native output with diagnostics; skins without a compatible Text meter are rejected. Imported skins start disabled. The service saves enabled skins and attempts to restore them on restart; a missing GNOME widget bridge is reported as an error rather than claiming display. A limited live clock was observed after a later GNOME login; the extension was subsequently uninstalled when the renderer's overview issue remained unresolved. Neither this parser nor the native bridge runs arbitrary Rainmeter measures, plugins, scripts, or interactive actions.

INI is capped at 1 MiB, images at 16 MiB, sections at 512, options at 4096, expanded values at 16 KiB and recursion at 16. Paths reject absolute paths, drive/UNC paths, traversal, symlink components and archive-looking components (`.rmskin`, `.zip`, `.7z`, `.rar`, `.tar`, `.gz`). Archives, including nested archives, must **not** be fed to this API: it does not unpack or inspect them. A future importer must impose independent decompression quotas, reject nesting and symlinks, and stage files into an immutable trusted directory before calling `inspect_skin`. File-system checks cannot prevent time-of-check/time-of-use races if an attacker can mutate `root` concurrently; do not use returned paths as a security capability, and copy validated files into trusted storage before rendering.
